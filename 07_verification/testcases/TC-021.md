## Context

Golden Thread test case. The measured time must be assessed against the FTTI of SG-01 (300 ms), not
merely against "a reaction occurred". The result is duty-dependent, so the PWM duty is fixed in the
preconditions and the test is run at both ends of the specified range.

## Change note (phase 3 refinement, hardware-engineer)

Expected result "within 50 ms plus debounce" replaced by the explicit 80 ms detection budget;
preconditions now fix the PWM duty; steps now capture off-phase samples. Status dropped to `draft`.
