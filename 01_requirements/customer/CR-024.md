## Context

Customer requirement from phase 1 (SYS.1), added in a later SYS.1 increment (illuminance topic).

`CR-010` demands only compliance with the photometric requirements of ECE R112/R123. This record
adds the customer's own, tighter level for the base light distribution and gives a single
measuring point that can be tested pass/fail.

The measuring convention (screen distance, point designations, aim) is captured as assumption
`A-22`, because the customer specification extract does not state it.
