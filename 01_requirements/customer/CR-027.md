## Context

Customer requirement from phase 1 (SYS.1), added in a later SYS.1 increment (illuminance topic).

The requesting source (driver input, or the vehicle via CAN FD based on speed and navigation data)
is deliberately left open at customer-requirement level; the concrete trigger set belongs to
`SYS.2`.

Distinct from `CR-001` (300 ms to activate the low beam from the switch), which bounds switch-on,
not a redistribution between two active light distributions. The set of supported modes is not
fixed by this record and has to be agreed with the OEM.
